# План реализации центральной панели настроек

## Цель

Заменить автоматически закрывающийся системный `popover` собственной центральной модальной карточкой MiniCam, сохранив существующую логику настроек.

## Шаги

1. Изменить контракт `SettingsPanel`: вместо управления внешним `isPresented` передавать явные действия `onCancel` и `onSaved`.
2. Оформить карточку в стиле MiniCam: тёмный фон, салатовый акцент, тонкая граница, крестик, компактные строки и собственные кнопки.
3. В `CameraPlayerView` удалить `.popover` у шестерёнки и добавить центральный слой поверх всего содержимого плеера.
4. Добавить затемнение и блокировку фоновых элементов, пока форма открыта.
5. Поддержать закрытие крестиком, «Отменой» и Escape без применения черновика.
6. Оставлять карточку открытой при выборе папки и при ошибке сохранения; закрывать только после успешного `applySettings`.
7. Собрать Debug и Universal Release для `x86_64` и `arm64`.
8. Вручную проверить выбор папки, отмену, сохранение, центрирование и отсутствие изменений размеров плеера и таймлайна.

## Автоматические проверки

Новые UI-тесты не добавляются. Существующие две ключевые проверки настроек и миграции запускаются повторно, чтобы подтвердить отсутствие регрессии бизнес-логики.
