# План плавной перемотки на Intel Mac

1. Добавить проверяемый выбор параметров VLCKit для Intel и Apple Silicon.
2. На Intel разрешить отбрасывание и пропуск опоздавших кадров; на Apple Silicon сохранить текущие параметры.
3. Подключить выбранный профиль при создании каждого основного проигрывателя.
4. Добавить одну автоматическую проверку различия профилей архитектур.
5. Собрать Universal Release и проверить архитектуры `x86_64`, `arm64` и минимальную macOS 12.
