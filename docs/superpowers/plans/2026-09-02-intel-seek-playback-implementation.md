# План надёжного перехода между RTSP-потоками

1. Отменить экспериментальные различия параметров воспроизведения Intel и Apple Silicon.
2. После остановки старого VLC-проигрывателя сохранять очередь перехода закрытой ещё 400 мс.
3. Во время ожидания сохранять только последнюю выбранную позицию архива.
4. Отменять таймер освобождения канала при полной остановке проигрывателя.
5. Запустить минимальные проверки очереди переходов.
6. Собрать Universal Release и проверить `x86_64`, `arm64`, минимальную macOS 12 и переход на архив через Rosetta.
