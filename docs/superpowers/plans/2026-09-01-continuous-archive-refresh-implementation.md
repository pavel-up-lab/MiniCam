# План постоянного обновления архива

1. В `AppContainer` заменить задачу обновления только прямого эфира на общую задачу синхронизации архива.
2. Запускать единственный цикл после успешного подключения и останавливать предыдущий цикл перед переподключением.
3. Не останавливать цикл при паузе, переходе в архив, пошаговой перемотке и перемещении таймлайна.
4. Убрать из цикла проверку состояния плеера, сохранив последовательный запрос последних двух минут каждые 15 секунд.
5. Добавить узкую проверку независимости синхронизации от состояния воспроизведения, затем собрать приложение.
