# План реализации локального кэша кадров

## 1. Изолировать файловое хранилище

- Добавить `FrameCacheStore` с индексом кадров по времени.
- Восстанавливать индекс из имён JPEG при запуске.
- Находить ближайший кадр в заданном допуске без чтения всех изображений.
- Хранить только последние 36 часов и удалять просроченные файлы.
- Записывать готовые JPEG атомарно в каталог Application Support.

## 2. Получать кадры не ниже 720p

- Добавить в `HikvisionClient` получение текущего JPEG основного канала через Digest HTTP.
- Запрашивать один снимок каждые 2 секунды без параллельных запросов.
- Проверять, что исходное изображение не ниже 1280×720.
- Уменьшать подходящий снимок до рабочего размера с сохранением пропорций и сохранять JPEG качества 60%.
- При неподходящем HTTP-снимке использовать отдельный беззвучный основной RTSP-поток как запасной источник 1280×720.
- Не останавливать основной эфир при ошибках кэша.

## 3. Перевести предпросмотр на локальные кадры

- Удалить использование `VLCMediaThumbnailer` и архивных RTSP-запросов из `ArchivePreviewController`.
- Загружать ближайший локальный JPEG асинхронно.
- Игнорировать устаревший результат при быстром движении шкалы.
- Сохранять последний успешный кадр только внутри накопленного диапазона.
- Скрывать старый кадр и показывать начало доступного диапазона при выборе времени вне кэша.

## 4. Подключить жизненный цикл

- Настроить хранилище и рекордер в `AppContainer` после подключения камеры.
- Запустить запись кэша один раз и продолжать её при переключении эфир/архив.
- Остановить рекордер при уничтожении контейнера.
- Подключать скрытую поверхность запасного RTSP-рекордера только когда HTTP-снимки недоступны.
- Вписывать предпросмотр целиком на чёрном фоне без обрезки краёв.

## 5. Сделать переход к видео конечным

- Связать каждый запуск основного потока с номером перехода.
- Скрывать предпросмотр только по первому кадру соответствующего потока.
- Плавно растворять локальный кадр за 120 мс.
- Добавить страховочное скрытие через 3 секунды.
- Для свежего неиндексированного края обновлять архив и возвращаться в эфир, если записи ещё нет.

## 6. Проверить

- Добавить только проверки выбора ближайшего времени, ограничения допуска и границы хранения.
- Собрать Debug для macOS 12.
- На реальной камере убедиться, что файлы появляются каждые 2 секунды и эфир продолжает работать.
- Проверить фактическое разрешение JPEG, быстрый скраббинг, отсутствие обрезки, поведение вне кэша и конечный переход к архивному видео.
- После подтверждения собрать Universal Release для Intel и Apple Silicon.
