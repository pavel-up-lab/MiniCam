# План заглушки перемотки без кадров

1. Добавить одну проверку `ArchivePreviewController`: запрос времени без локального JPEG публикует состояние недоступности и сохраняет выбранное время.
2. Реализовать сохранение последнего запрошенного времени, не меняя поиск ближайшего кадра и параметры локального кэша.
3. Заменить небольшое сообщение о недоступности непрозрачной полноэкранной заглушкой с выбранными датой и временем; нижнюю панель и календарь оставить поверх неё.
4. Расширить существующий переход так, чтобы заглушка удерживалась после отпускания таймлайна до первого кадра архивного потока либо до действующей трёхсекундной страховки.
5. Запустить одну новую проверку, существующие модульные проверки и сборку Debug.
6. Проверить вручную переход к участку архива без накопленных кадров; после подтверждения собрать универсальное приложение для Intel и Apple Silicon.
