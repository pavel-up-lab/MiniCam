# План последовательной перемотки архива

1. Выделить небольшую проверяемую очередь запросов воспроизведения: во время остановки она хранит только последний запрос и разрешает запустить его ровно один раз.
2. Подключить очередь к `VLCPlaybackController`: активный поток сначала останавливается, новый запускается после состояния `stopped` либо по короткому защитному таймеру.
3. Добавить одну автоматическую проверку замены нескольких ожидающих запросов последним.
4. Собрать Debug и Universal Release для `x86_64` и `arm64`.
5. Проверить на камере переход вперёд внутри архива, несколько быстрых переходов и возврат в прямой эфир.
