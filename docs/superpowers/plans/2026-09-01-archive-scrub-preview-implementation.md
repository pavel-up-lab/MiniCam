# План реализации предпросмотра архива

## 1. Добавить отдельный контроллер кадров

- Создать `ArchivePreviewController` на основе `VLCMediaThumbnailer`.
- Передавать профиль и учётные данные камеры через существующую настройку контейнера.
- Формировать архивный URL от выбранной даты существующим `HikvisionPlaybackURL`.
- Публиковать только последнее актуальное `NSImage` и дату кадра.

## 2. Ограничить запросы к камере

- Принимать новые выбранные даты не чаще одного запуска каждые 500 мс.
- Одновременно выполнять только один запрос кадра.
- Пока запрос выполняется, хранить только самое новое ожидающее положение.
- Игнорировать результат, если пользователь уже выбрал более новую дату.
- Очищать ожидающий запрос при сворачивании или завершении работы экрана.

## 3. Передавать предварительный выбор из таймлайна

- Добавить в `ArchiveTimelineView` обработчик `onPreview`.
- Вызывать его при движении детальной и обзорной шкал.
- Сохранить `onCommit` только для отпускания шкалы, чтобы основной RTSP-поток не перезапускался многократно.
- В `AppContainer` выбирать подходящий сегмент и передавать его контроллеру предпросмотра.

## 4. Закрыть чёрный переход изображением

- Показать превью поверх `VLCVideoSurface` на всю область с сохранением пропорций.
- Подписать выбранное время и ближайший ключевой кадр.
- После отпускания оставить изображение видимым во время открытия нового потока.
- В `VLCPlaybackController` публиковать номер первого временного события каждого нового потока.
- Скрывать превью только после первого события потока, запущенного после окончательного выбора.

## 5. Проверить

- Собрать Debug для macOS 12 без добавления новых UI-тестов.
- На реальной камере проверить медленное и быстрое движение обеих шкал.
- Убедиться, что устаревшие кадры не появляются, основной эфир не тормозит, а чёрная вспышка при отпускании закрыта последним превью.
- После визуального подтверждения собрать Universal Release для `arm64` и `x86_64`.
