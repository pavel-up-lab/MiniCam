# План реализации событий движения

## 1. Подготовить Core ML-модель

- Добавить воспроизводимый скрипт экспорта официальной YOLOX-Nano в Core ML ML Program с целью macOS 12, входом 416×416 и весами FP16.
- Поместить итоговую `YOLOXNano.mlpackage` в ресурсы приложения и добавить сведения об Apache 2.0 в файл лицензий третьих сторон.
- Добавить тонкую обёртку `YOLOXObjectDetector`, которая принимает архивный `CGImage`, выполняет Core ML-запрос с низким приоритетом и возвращает только согласованные классы с уверенностью от 0,45.
- Реализовать декодирование результата и NMS отдельно от Core ML-вызова, чтобы эту логику можно было проверить без запуска камеры.
- Проверить, что модель компилируется Xcode для Universal-приложения с минимальной системой macOS 12 и загружается через CPU/GPU на текущем Mac.

## 2. Описать чистые типы событий

- Добавить типы категорий `person`, `car`, `truck`, `bus`, `motorcycle`, `bicycle`.
- Добавить результат распознавания с категорией, уверенностью и нормализованной областью.
- Добавить `MotionEvent` с идентификатором, временем, набором категорий и именем JPEG.
- Не переносить Core ML, VLCKit или SwiftUI в эти доменные типы.

## 3. Выбирать только новый архивный диапазон

- Добавить `ArchiveAnalysisCursor`, который начинает работу с переданного времени подключения.
- На каждом пятнадцатисекундном обновлении пересекать диапазон после курсора с актуальными `RecordingSegment` и разбивать работу по границам записей.
- Не анализировать время до запуска, не создавать повторные диапазоны и ограничивать ожидающий хвост последней минутой.
- Сначала написать одну группу проверок: старт с текущего времени, рост текущего сегмента, переход через границу сегментов и ограничение отставания; затем реализовать минимальную логику.

## 4. Реализовать определение начала движения

- Добавить независимый `MotionEventTracker`, принимающий время кадра и массив распознаваний.
- Сопоставлять объекты одного класса по IoU от 0,2 либо расстоянию центров до 15% диагонали.
- Считать объект движущимся при смещении центра от 1% диагонали либо изменении ширины/высоты от 8%.
- Создавать событие на переходе в движение, не дублировать непрерывное движение, подтверждать остановку двумя спокойными интервалами и забывать объект после 30 секунд отсутствия.
- Объединять начала движения из одной выборки в одно событие с несколькими категориями.
- Проверить только согласованные переходы состояний: неподвижность, начало движения, непрерывное движение, остановка и повторный старт, второй объект, истечение 30 секунд.

## 5. Хранить события три дня

- Добавить `MotionEventStore` в `Application Support/MiniCam/MotionEvents`.
- Атомарно сохранять метаданные и JPEG 1280×720, загружать события новыми сверху и пропускать повреждённые записи.
- При запуске и после записи удалять метаданные и JPEG старше трёх дней, включая оставшиеся без метаданных изображения.
- Одной файловой проверкой подтвердить сохранение/загрузку и удаление просроченной пары; визуальное качество JPEG автоматически не проверять.

## 6. Получать кадры только из нового архива

- Добавить отдельный `ArchiveFrameSampler` на собственном скрытом `VLCMediaPlayer`; основной `VLCPlaybackController` и локальный кэш перемотки не переиспользовать.
- Формировать архивный URL с точными `starttime` и `endtime`, передавать учётные данные через опции VLCKit и устанавливать скорость около 4×.
- Последовательно снимать JPEG 1280×720 примерно раз в секунду архивного времени. Не держать больше одного ожидающего снимка и удалять временные файлы после обработки.
- Завершать диапазон по его конечному времени, отмене или ошибке. Одну ошибку открытия повторять, затем сообщать координатору о пропуске.

## 7. Связать выборку, модель и журнал

- Добавить `ArchiveMotionAnalyzer`, который последовательно принимает диапазоны, передаёт кадры модели и трекеру и сохраняет кадр первой выборки для созданного события.
- Не запускать параллельные Core ML-запросы или VLC-плееры. При отставании объединять ожидание и оставлять не больше последней минуты.
- Публиковать состояния `idle`, `analyzing` и `temporarilyUnavailable`, не превращая отдельную ошибку диапазона в ошибку просмотра камеры.
- Сбрасывать трекер и курсор при повторном подключении к другой камере.

## 8. Подключить анализ к обновлению архива

- Создать анализатор и хранилище в `AppContainer`.
- После успешного подключения настроить профиль и учётные данные, загрузить события за три дня и поставить курсор на текущее время.
- Вызывать планирование анализа только из периодического пятнадцатисекундного обновления. Обновления, вызванные перемоткой или продолжением архива, не должны запускать распознавание.
- При отключении или новом подключении отменять активный диапазон и очищать ожидающую очередь.

## 9. Добавить правую выдвижную панель

- Создать отдельный `MotionEventsPanel` вместо расширения уже большого `CameraPlayerView` карточками и файловой логикой.
- Разместить панель поверх правой части видео, выше видеослоя и ниже нижней панели управления; ширина открытого состояния около 340 px.
- Показать крупные карточки варианта A: кадр во всю ширину, дата, точное время и метки. Новые события идут сверху.
- В свёрнутом виде оставить узкую вкладку со стрелкой и количеством непросмотренных событий; счётчик сбрасывается при открытии панели и не сохраняется между запусками.
- Показать пустое состояние и спокойный статус временной недоступности.
- При нажатии вызвать существующий `seek(to:)`, автоматически свернуть панель и не добавлять новый способ архивного воспроизведения.

## 10. Проверить на реальной камере

- Запустить выбранные доменные и файловые проверки, затем существующие 18 модульных проверок и Debug-сборку.
- На камере проверить неподвижного человека/автомобиль, начало движения, непрерывное движение без дублей, одновременные категории и второго объекта.
- Проверить, что событие появляется после ближайшего обновления архива, карточка открывает нужный момент, а прямой эфир и ручная перемотка остаются плавными.
- Замерить время обработки пятнадцатисекундного диапазона и загрузку CPU на текущем Mac. Если диапазон не успевает до следующего обновления, сначала уменьшить частоту выборок, не менять основной VLC-плеер.
- После визуального подтверждения собрать Universal Release, проверить архитектуры `arm64` и `x86_64` и минимальную систему macOS 12.
