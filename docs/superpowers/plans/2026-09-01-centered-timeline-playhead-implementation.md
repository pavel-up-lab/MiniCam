# План реализации центрального таймлайна

## 1. Изолировать расчёты времени

- Добавить `ArchiveTimelineScale` без зависимостей от SwiftUI и VLCKit.
- Зафиксировать детальный масштаб: 0,5 секунды на точку интерфейса.
- Реализовать ограничение диапазоном архива, прилипание к эфиру в пределах 3 секунд и преобразование обзорной позиции `0...1` в дату.
- Добавить один компактный набор тестов только для этих трёх расчётов.

## 2. Создать отдельный компонент шкалы

- Добавить `ArchiveTimelineView` в `MiniCam/UI/Player`.
- Нарисовать секундные и минутные риски относительно неподвижной центральной линии.
- Показать над линией точное целевое время.
- Во время жеста показать пометку `ближайший ключевой кадр`.
- Отправлять выбранную дату только по завершении жеста.
- Добавить под детальной шкалой тонкий обзорный `Slider` всего архива.

## 3. Подключить к плееру

- Заменить текущий основной `Slider` в `CameraPlayerView` новым компонентом.
- Синхронизировать шкалу с `playback.currentDate`, не перезаписывая выбор во время перетаскивания.
- Сохранить существующую кнопку `В эфир` и состояние прямого эфира.
- Не менять настройки VLCKit, Hikvision API и безопасное хранение пароля.

## 4. Проверить

- Запустить существующие тесты и новый набор расчётов.
- Собрать Debug и Universal Release для `arm64` и `x86_64` с macOS 12.0.
- Открыть приложение и вручную проверить: точный выбор последних секунд, дальний переход обзорным ползунком, архив и возврат в эфир.
