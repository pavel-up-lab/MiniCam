# План реализации скриншотов

## Цель

Сохранять чистый текущий кадр активного VLC-плеера как PNG исходного разрешения, используя Рабочий стол по умолчанию или отдельную папку из настроек.

## Шаги

1. Расширить `AppSettings` отдельными bookmark и отображаемым путём папки скриншотов с обратной совместимостью старого JSON.
2. Дополнить существующую проверку `AppSettingsStore` загрузкой старого формата и round-trip новых полей.
3. Добавить в `VLCPlaybackController` асинхронное сохранение одного текущего кадра, уникальное имя, обработку callback и тайм-аут.
4. В `AppContainer` разрешать и удерживать отдельный security-scoped доступ, использовать Рабочий стол по умолчанию и публиковать фактическую папку/предупреждение.
5. Расширить `applySettings`, чтобы выбранная папка скриншотов сохранялась только после нажатия `Сохранить`.
6. Добавить в `SettingsPanel` отдельную карточку скриншотов с выбором папки и возвратом на Рабочий стол.
7. Добавить слева от шестерёнки кнопку снимка и краткое уведомление об успехе или ошибке.
8. Запустить одну проверку настроек, существующую проверку миграции, Debug-сборку и Universal Release для `x86_64` и `arm64`.
9. Вручную проверить прямой эфир, архив, паузу, исходное разрешение PNG и отсутствие элементов интерфейса.

## Ограничение тестов

Новые UI-тесты и тесты VLCKit не добавляются: реальный кадр и callback надёжно проверяются только на активной камере. Автоматически покрывается только сериализация и обратная совместимость настроек.
