# Надёжный переход между RTSP-потоками

## Цель

Устранить чёрный экран и остановку воспроизведения после перемотки архива, сохранив совместимость с Intel Mac под macOS Monterey и Apple Silicon.

## Подтверждённая причина

Диагностический запуск `x86_64`-сборки через Rosetta воспроизвёл проблему локально. При переходе с прямого эфира в архив MiniCam отправляет камере RTSP-команду `TEARDOWN` и сразу открывает новый архивный сеанс. Камера ещё не успевает освободить предыдущий канал и отвечает на `SETUP` нового сеанса кодом `453 Not Enough Bandwidth`. В этот момент у основного проигрывателя не остаётся активного RTSP-соединения, поэтому экран становится чёрным.

Настройки декодирования Intel не являются причиной. Экспериментальное разрешение отбрасывать или пропускать кадры отменяется; обе архитектуры снова используют одинаковые параметры изображения.

## Решение

После подтверждения остановки старого проигрывателя MiniCam выдерживает 400 мс перед созданием нового VLC-проигрывателя и открытием следующего RTSP-сеанса. Этого достаточно для получения и обработки камерой `TEARDOWN`, при этом задержка перехода остаётся короткой.

На время ожидания очередь перехода остаётся закрытой. Если пользователь ещё двигает таймлайн, приложение хранит только последнюю выбранную позицию. По окончании паузы открывается один RTSP-сеанс сразу в этой позиции; промежуточные запросы не отправляются камере.

Если VLCKit не сообщает об остановке, существующий резервный таймер срабатывает через 750 мс, после чего применяется та же пауза освобождения канала. Явная остановка приложения отменяет оба таймера и очищает очередь.

## Проверка

Существующая автоматическая проверка очереди подтверждает, что при нескольких быстрых переходах запускается только последний запрос. Выполняется Universal Release для `x86_64` и `arm64` с минимальной macOS 12. Главная проверка выполняется на диагностическом Intel-запуске через Rosetta: в журнале после `TEARDOWN` следующий `SETUP` должен получить `200 OK`, после чего архивное видео должно начать воспроизводиться.
