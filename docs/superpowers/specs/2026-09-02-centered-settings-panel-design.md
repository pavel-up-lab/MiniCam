# Центральная панель настроек

## Причина изменения

Текущая форма открывается системным SwiftUI `popover`. При запуске `NSOpenPanel` для выбора папки macOS переключает активное окно, и transient-popover автоматически закрывается. Пользователь теряет возможность проверить выбранную папку и нажать «Сохранить».

## Интерфейс

- Кнопка-шестерёнка остаётся в правом верхнем углу плеера.
- Вместо `popover` внутри `CameraPlayerView` появляется собственный модальный слой.
- Видео затемняется, а компактная карточка варианта A располагается строго по центру доступной области окна.
- Карточка использует визуальный язык MiniCam: почти чёрный фон, тонкая светлая граница, салатовый акцент, скругления и компактные системные шрифты.
- Компоновка видео, календаря, таймлайна и правой панели событий не меняется.

## Поведение

- При открытии карточка копирует сохранённые настройки в локальный черновик.
- Выбор папки через `NSOpenPanel` не закрывает карточку и только обновляет черновик.
- Фоновые элементы плеера не принимают нажатия, пока настройки открыты.
- Карточка закрывается только крестиком, кнопкой «Отмена», клавишей Escape либо после успешного сохранения.
- Крестик, Escape и «Отмена» отбрасывают несохранённый черновик.
- Во время переноса данных кнопки изменения и сохранения недоступны, форма показывает состояние переноса.

## Сохранение и ошибки

- «Сохранить» вызывает существующий `AppContainer.applySettings`.
- При успехе карточка закрывается и новое состояние становится исходным для следующего открытия.
- При ошибке карточка остаётся открытой, черновик сохраняется, а сообщение показывается внутри карточки.
- Существующая безопасная миграция, резервная внутренняя папка и предупреждение на шестерёнке не меняются.

## Компоненты

- `CameraPlayerView` управляет показом модального слоя и блокирует взаимодействие с фоном.
- `SettingsPanel` отвечает только за внешний вид, черновик, выбор папки и команды сохранения/отмены.
- `AppContainer` и хранилища не требуют изменения бизнес-логики.

## Проверка

Автоматический UI-тест не добавляется: это поведение надёжнее проверить вручную и пользователь просил минимальное число тестов. Проверяется:

1. форма остаётся открытой после выбора папки;
2. «Отмена», крестик и Escape не применяют изменения;
3. при ошибке сохранения форма остаётся открытой;
4. при успехе форма закрывается;
5. карточка остаётся по центру при изменении размера окна;
6. фон не принимает нажатия, а размеры видео и таймлайна не меняются.

## Совместимость

- macOS Monterey 12 и новее;
- Intel `x86_64` и Apple Silicon `arm64`;
- только API SwiftUI/AppKit, доступные в macOS 12.
