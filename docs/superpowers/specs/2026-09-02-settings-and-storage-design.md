# Настройки трекинга и хранения

## Цель

Добавить в MiniCam расширяемую форму настроек. В первой версии форма управляет двумя параметрами:

1. включением распознавания начала движения;
2. выбором внешней папки для всех объёмных локальных данных.

Настройки не должны влиять на основной эфир, воспроизведение архива или существующую компоновку таймлайна.

## Интерфейс

- В правом верхнем углу плеера располагается отдельная кнопка с шестерёнкой. Она не меняет размеры видео и не входит в правую панель событий.
- Кнопка открывает компактную форму поверх видео.
- Форма содержит:
  - переключатель `Распознавать движение`;
  - текущую папку хранения;
  - кнопку `Выбрать…`;
  - кнопку `Вернуть внутреннюю папку`;
  - состояние хранения и переноса;
  - кнопки `Сохранить` и `Отмена`.
- Закрытие или отмена формы не применяет несохранённые изменения.
- При временном использовании внутреннего хранилища на кнопке настроек показывается предупреждение.
- Состояния хранения в форме:
  - внешняя папка доступна;
  - временно используется внутренняя папка;
  - выполняется перенос данных;
  - перенос будет повторён после ошибки.

Форма создаётся отдельным SwiftUI-компонентом. Существующие календарь, таймлайн, транспортные кнопки и панель событий не меняют свою компоновку.

## Настройки

Добавляется отдельная модель настроек приложения, сохраняемая в `UserDefaults`:

- `isMotionTrackingEnabled: Bool`, значение по умолчанию `true`;
- сохранённый доступ к выбранной внешней папке;
- отсутствие внешней папки означает использование стандартного внутреннего хранилища.

Для устойчивого доступа к папке между запусками macOS сохраняется security-scoped bookmark. Путь используется только для отображения и диагностики; источником доступа является bookmark.

## Поведение трекинга

- При включённом трекинге новые архивные кадры проходят через YOLOX-Nano и `MotionEventTracker`.
- При выключенном трекинге Core ML и создание новых событий отключаются.
- Архивный сборщик продолжает получать кадры и пополнять кэш перемотки независимо от переключателя.
- Уже созданные события сохраняются до окончания существующего трёхдневного срока.
- Повторное включение начинает анализ только новых архивных данных с момента включения. Старый материал задним числом не анализируется.

## Структура хранения

Внутренний корень по умолчанию:

`Application Support/MiniCam`

При выборе внешней папки внутри неё создаётся подпапка `MiniCam`. В активном корне находятся:

- `FrameCache/v2-720p` — кадры перемотки;
- `MotionEvents` — JSON-карточки и JPEG событий.

Выбор папки распространяется сразу на оба вида данных. Независимые пути для кэша и событий не поддерживаются.

## Координатор хранения

Единый `StorageCoordinator` отвечает за:

- текущий предпочтительный корень;
- текущий фактически доступный корень;
- проверку внешней папки;
- переключение на внутренний резерв;
- перенос и объединение файлов;
- публикацию состояния для формы и предупреждения на кнопке.

`FrameCacheStore` и `MotionEventStore` получают расположение через координатор и не принимают самостоятельных решений о внешнем диске.

## Выбор и смена папки

После нажатия `Сохранить`:

1. координатор проверяет доступ к новой папке и возможность записи;
2. создаёт структуру `MiniCam`;
3. переводит новые записи в безопасный активный корень;
4. копирует существующий кэш и события;
5. проверяет наличие и размер скопированных файлов;
6. удаляет исходные копии только после успешной проверки;
7. публикует завершённое состояние.

При выборе другой внешней папки переносятся данные и из прежней внешней папки, и из внутреннего резерва. При возврате к внутреннему хранению доступные внешние данные переносятся внутрь тем же безопасным способом.

Конфликты разрешаются без создания дублей:

- кадры имеют имя по времени и объединяются по имени файла;
- события имеют UUID и объединяются по UUID;
- существующий корректный файл не удаляется до проверки второй копии.

## Временно недоступный внешний диск

- Если bookmark не разрешается, папка отсутствует или тест записи завершается ошибкой, активным становится внутренний корень.
- Эфир, архив, сбор кадров и трекинг продолжаются.
- На кнопке настроек появляется предупреждение, а форма сообщает о временном внутреннем хранении.
- Внешняя папка проверяется при запуске и при штатном 15-секундном обновлении архива.
- После восстановления доступа внутренние файлы автоматически объединяются с внешними.
- После успешного объединения новые записи снова направляются наружу.
- Ошибка переноса не удаляет исходные файлы. Повтор выполняется при следующей проверке.

## Согласованность во время переноса

- В каждый момент существует один активный корень для новых записей.
- Перенос выполняется последовательно в фоне и не блокирует интерфейс или воспроизведение.
- Новые файлы, появившиеся во время переноса, остаются в активном корне и попадают в следующий проход объединения.
- После переноса координатор повторно проверяет источник; завершение публикуется только когда неперенесённых файлов не осталось.

## Ошибки

- Ошибки выбора папки показываются внутри формы и не меняют сохранённые настройки.
- Ошибка внешней записи вызывает немедленный переход на внутреннее хранилище.
- Ошибка копирования оставляет обе доступные копии и состояние ожидания повторного переноса.
- Повреждённый bookmark не приводит к потере внутреннего архива; пользователь может выбрать папку повторно.

## Минимальные проверки

Автоматически проверяются только сценарии, которые трудно надёжно оценить визуально:

1. сохранение и восстановление переключателя и выбранной папки;
2. переход на внутренний корень при недоступной внешней папке;
3. безопасное объединение внутренних и внешних данных после восстановления доступа, включая конфликты имён.

Вручную проверяются:

- положение кнопки в правом верхнем углу;
- форма, отмена и сохранение;
- системный выбор папки;
- предупреждение и отображение состояния;
- сохранение размеров видео, таймлайна и панели событий.

## Совместимость

- macOS Monterey 12 и новее;
- Intel `x86_64` и Apple Silicon `arm64`;
- только API, доступные в macOS 12;
- настройки не требуют сервера или облачного аккаунта.

## Не входит в эту версию

- отдельные папки для кэша и событий;
- настройка срока хранения;
- настройка частоты или качества кадров;
- очистка кэша из формы;
- дополнительные параметры будущих версий.
